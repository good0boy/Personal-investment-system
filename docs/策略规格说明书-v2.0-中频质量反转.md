## 1. 策略全貌

**一句话**：在上证指数近 20 个交易日未明显下跌时，买入沪深主板/创业板中
「**近期温和偏弱（反转）+ 基本面成长为正 + 低波动 + 低换手 + 成交额达标**」的股票，
**每 5 个交易日评估一次建仓**、最多持 10 只、每只 10% 仓位，**持有满 30 个交易日**即卖出
（另有 5 条提前退出：质量恶化 / ST·跌停 / 过度兑现 / 止损（×p）/ 止盈（×p 或绝对 6%））。

**性质**：**中频 · 逆向 + 质量 + 低风险**（**不是**追涨）。

**性格**（必须清楚）：
- **持有期长、换手低** → 年化交易成本目标 **≤3%**（实测 **1.65%**），远低于 v1.6 的 7.8%
- **买的是"没人要的"**（反转 + 低波动 + 低换手）→ 收益来源与追涨策略完全相反
- **不做固定止盈、不设紧止损**（v1.5 已实测"止损越松越好"，紧止损会一起打掉赢家）
- **靠广度**：10 只分散，单票权重低 → 单票踩雷不致命

**为什么这么设计**（依据 `docs/回测与策略研究.md`）：
1. 根因：alpha 在**隔夜漏光**（买入强势股 → 次日平均低开 1.8%）→ **信号方向必须反着做**；
2. `ret_50` 分层单调性 **−1.00**（全组一致反向，形状最干净）；`volatility_20` −0.70、`turnover_20` −0.60；
3. `revenue_yoy` / `profit_yoy` 是全部因子里**唯二 IC 为正且单调 +1.00** 的 → 当**质量门**用（量级弱，不当收益引擎）；
4. 持有成本随频率急剧下降（10 日 4.9%/年 → 30 日约 1.9%）→ **频率本身就是 alpha 杠杆**。

### 2.2 开仓闸门（信号日 T 的截面，须全部通过）

> 可交易性过滤（非 ST/停牌/新股<90/一字板/非目标板块/60 日禁买）由**引擎股票池**负责，
> 策略侧**不重复实现**（见 `ctx.universe.symbols`）。

```
【门 1 · 大盘非急跌】
   上证指数 近 20 个交易日累计涨跌幅 > −10%
   → 否则本轮不建仓（已持仓不动）

【门 2 · 反转门（不追高）】
   rank_pct(ret_50) ≤ 0.50        —— 不买近 50 日最强的半数（截面百分位秩）
   AND max_ret_20 ≤ 0.15          —— 排除近 20 日内有涨停式脉冲的标的

【门 3 · 质量门（基本面成长）】
   profit_yoy > 0 AND revenue_yoy > 0
   —— 按**公告日 as-of 对齐**（NOTICE_DATE，防未来函数）
   —— 个股缺值 → 不通过（不猜）；因子整体不可用 → 该门降级并告警

【门 4 · 低风险门】
   volatility_20 ≤ 截面中位数
   AND turnover_20 ≤ 截面中位数

【门 0 · 流动性下限】
   amount_mean_20 ≥ 50,000,000 元   —— 近 20 日日均成交额
   —— 与 turnover_20 是**两个口径**：换手率按股本归一，成交额刻画"能承接多少钱"

【排序与执行】
   通过全部门的候选，按下面 5 个维度做**逐日截面百分位秩**后**等权平均**打分：
       · ret_50       方向 −1（越弱越好）
       · profit_yoy   方向 +1
       · revenue_yoy  方向 +1
       · volatility_20 方向 −1
       · turnover_20  方向 −1
   降序取前 N 只（N = max_positions − 当前持仓数），**空位才补，不强制换手**
   稳定排序 + 代码 tiebreaker（保证同一配置跑两次逐行一致）
   T+1 开盘买入，每只投入 10% × 当前总资产
```

**口径细节**：
- 百分位秩用 `pandas.Series.rank(pct=True)`（平均秩口径）；缺值（NaN）参与比较即为 False → **不通过**。
- **必须截面标准化再合成**：5 个维度量纲不同，直接相加等于让量纲大的独占权重。
- 打分维度至少要有 1 个可用，否则当日不建仓（不猜）。

### 2.3 退出规则（6 个条件，任一触发即卖出）

| # | 条件 | 判定口径 | 执行 |
|---|---|---|---|
| 1 | **到期换仓** | 持有满 `hold_days_max`（默认 30）个交易日（**含首尾**计数） | T 日尾盘收盘价卖出 |
| 2 | **质量恶化** | 当日已公告的最新一期 `profit_yoy < 0` **或** `revenue_yoy < 0` | T 日尾盘收盘价卖出 |
| 3 | **风险事件** | `isST = 1`，或收盘跌停 | ST → 收盘价卖出；**跌停 → 顺延 T+1 开盘**（红线：不按理想价撮合） |
| 4 | **过度兑现** | 近 20 个交易日累计涨跌幅 **≥ +30%** | T 日尾盘收盘价卖出 |
| 5 | **止损（v2.1）** | **毛收益率 ≤ −`stop_loss_p_mult` × p** | T 日尾盘收盘价卖出 |
| 6 | **止盈（v2.1）** | **毛收益率 ≥ `take_profit_p_mult` × p** **或** **≥ `take_profit_abs`** | T 日尾盘收盘价卖出 |

#### 条件 5/6 的精确定义与基准 `p`（v2.1 新增；**p 口径 v2.2 改版**）⚠️

**阈值基准 `p` = 最近 5 个交易日「每日涨跌幅绝对值」的均值**（小数）：

```python
lo   = di - 5 + 1
ts   = ctx.market.trade_status[lo:di+1, si]     # 1=可交易 / 0=停牌 / -1=无行
seg  = ctx.market.pct_chg[lo:di+1, si]          # ★ 单位是【百分数】（1.15 = +1.15%）
if not (窗口长度==5 and 全部 ts==1 and 全部 seg 有限):
    p = NaN                                     # → 本规则当日不触发（不误杀）
else:
    p = mean(abs(seg)) / 100.0                  # 近 5 日「日均绝对涨跌幅」，小数

gross = ctx.market.close_at(symbol, di) / pos.entry_price - 1.0     # 毛收益率

stop_loss   = stop_loss_p_mult  > 0 and p > 0 and gross <= -stop_loss_p_mult * p
take_profit = (take_profit_p_mult > 0 and p > 0 and gross >= take_profit_p_mult * p) \
              or (take_profit_abs > 0 and gross >= take_profit_abs)
```

- **不是振幅** —— 与 v1.4/v1.5 `momentum` 的「近 5 日平均振幅」是**不同口径**，别混用。
- ⚠️ **窗口内必须 5 天全部可交易**（`trade_status == 1`）且 `pct_chg` 有限，否则 `p` 不可用 → 不触发。
  为什么必须掩码：baostock 的**停牌日有行**（`has_data=True`），但 `trade_status=0` 且
  `pct_chg` 为 **0 或 NULL**（close 恒等于前收）—— 不掩码会把停牌日算进均值、**人为压低 p**。
- **`pct_chg` 是百分数** → 必须 ÷100（`engine.py` 里 `_mat("pct_chg")` 存的是 `1.15` 这种值）。
- **量级对照（实测 2024-11-15 全市场截面）**：

  | p 口径 | 中位 | 25% | 75% | 95% |
  |---|---|---|---|---|
  | v2.1 `\|近5日累计涨跌幅\|/5`（日间正负对消 → 偏小） | 0.93% | 0.52% | 1.52% | 2.83% |
  | **v2.2 `mean(\|日涨跌幅\|)`** | **2.25%** | 1.54% | 3.22% | 5.33% |

  → 新口径是旧口径的 **2.43 倍**：`1×p` 止损线由 −0.4%（"贴脸"）变成 **−2.25%（正常量级）**。
- **0 = 关闭**：`mult <= 0` / `abs <= 0` 时该规则恒不触发（参数**默认全 0** → 行为与 v2.0/M1 基线一致）。
- 全部**毛口径**（与条件 4 的 over_realized 一致）。
- 与其它条件**并存**：同一天多个条件成立时 reason 用 `|` 连接（如 `time_stop|stop_loss`）。

**多条件同时触发**：`reason` 用 `|` 记录全部（如 `time_stop|over_realized`）。

**口径细节**：

- ⚠️ **p 刻意取小** → 阈值等价于**日内级**。例：近 5 日只动 2% 的票 → p ≈ 0.4%，

- 毛口径；与 `time_stop` / `quality_broken` / `st` / `limit_down` / `over_realized` 并存，reason 用 `|` 连接。
- 退出原因沿用既有枚举 `stop_loss` / `take_profit`（无需改契约、无需改前端）。

**⚠️ 与 v2.0 的对比纪律**：v2.1 新增了参数键 → `run_id` 哈希改变（预期）；
**默认全 0 时回测结果应与 v2.0 基线逐位一致**（已作为回归检查项）。

> ⚠️ **本节的口径细节（`p` 的定义）已被 §7.7 的 v2.2 取代** —— 下文保留原文以存档当时的决策。

- 实现落点：`strategies/impl/quality_reversal.py::_p_absmean`（引擎零改动，策略侧直读矩阵）。
- 单测：`test_p_definition_is_mean_abs_daily_return`（±1% 交替路径：新口径 p=1% → 2×p 不触发；
  旧口径 p≈0 → 必触发，一条断言即可区分）、`test_p_unavailable_when_window_has_suspension`（停牌致 p 不可用 → 止损被推迟）。

**⚠️ 对比纪律**：默认参数下 `p` 规则是**关的**（全 0）→ 改口径**不影响默认行为**，
`v2.2-baseline` 应仍为 **+1.88%**（回归检查项）。

**M3b 合并验证（同批跑）**：M3 给出两条**正贡献**（关流动性门 +1.30pp、关过度兑现退出 +1.44pp），
本次补跑"两条合并 + hold=40 + 止损 3×p"共 3 档对照，回答**是否叠加**。结果见 §7.8。

### 7.8 M3b 合并验证结果：两条正贡献**叠加**（2026-10-06）

锚点 = 对齐口径基准 **+7.71%**。所有档的 stop/tp 均为**关闭**（`p` 口径变化不影响它们）。

| 配置 | 年化 | 累计 | 最大回撤 | Sharpe | 笔数 | 年化成本 | 超额 |
|---|---|---|---|---|---|---|---|
| 基线（v2.1 口径、p 规则关） | +1.88% | +8.94% | −28.23% | 0.19 | 334 | 1.65% | −5.83pp |
| **基线（v2.2 新代码，p 规则关）** | **+1.88%** | **+8.94%** | **−28.23%** | **0.19** | **334** | **1.65%** | **−5.83pp** |
| M3 · 关流动性门 | +3.18% | +15.54% | −22.97% | 0.27 | 331 | 1.66% | −4.53pp |
| M3 · 关过度兑现退出 | +3.32% | +16.24% | **−32.26%** | 0.27 | 329 | 1.63% | −4.39pp |
| ⭐ **合并（关流动性门 + 关过度兑现）** | **+5.06%** | **+25.54%** | **−23.11%** | **0.36** | 332 | 1.65% | **−2.65pp** |
| 合并 + `hold=40` | +4.81% | +24.17% | −30.95% | 0.34 | 259 | 1.30% | −2.90pp |
| 合并 + `hold=40` + 止损 `3×p` | **−1.03%** | −4.66% | −30.75% | 0.03 | 510 | 2.49% | −8.74pp |

**四条结论**：

1. ✅ **回归通过**：改 `p` 口径后的新代码、默认参数 = **+1.88%**，与 v2.1 基线**逐位一致**
   （年化/累计/回撤/Sharpe/笔数/成本 全部相同）→ **p 口径变更不影响默认行为**（规则默认关闭）。
2. ⭐⭐ **两条正贡献"超叠加"**：单关 Δ = +1.31pp / +1.44pp（相加预期 +2.75pp），
   **实际合并 Δ = +3.18pp（+5.06%）→ 比相加还高 0.43pp**。
   更关键的是**回撤**：单关"过度兑现"会把回撤从 −28.23% 恶化到 **−32.26%**，
   但**两条一起关掉后回撤变成 −23.11%（比基线还好）** → **同时改善了收益与回撤**，
   Sharpe 0.19 → **0.36（接近翻倍）**，超额缺口从 −5.83pp 收窄到 **−2.65pp（历版最小）**。
3. ⚠️ **`hold=40` 在合并档下没有增益**：合并 + hold=40 = +4.81%（比合并低 0.25pp），
   回撤反而恶化到 −30.95%。→ §7.6 里"hold=40 是唯一像高原的维度值"这一结论**只在未关闸门的配置下成立**，
   与 M3b 不矛盾（不同配置域）。**暂不改默认 `hold_days_max=30`**。
4. ❌ **止损在新 `p` 口径下依然有害**：合并 + hold=40 + 止损 `3×p`（≈ −6.75%）→ **−1.03%**、
   笔数 510（较合并档 332 增长 54%）、成本 2.49%。→ **与 §7.6 的"止损越松越好、关闭最好"同向**，
   即便把 `p` 放大到正常量级，**结论不变**。

> ⚠️ **尚未改变任何默认参数**：本节的合并档是**对照实验**，不是采纳。
> 若要把"关流动性门 + 关过度兑现"写进默认值，须主人拍板后按 §7.7 流程升版本。
> ⚠️ 本节每档**只跑 1 次**，没有做参数寻优确认；`data/sweep/v2.2-quality-rev-sweep/` 是在
> **未关这两条门**的配置域上扫的，故本节结论与它**不可直接叠加**。
