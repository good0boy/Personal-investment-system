## 1. 策略全貌

**一句话**：在上证指数近 20 个交易日未明显下跌时，买入沪深主板/创业板中
「**近期温和偏弱（反转）+ 基本面成长为正 + 低波动 + 低换手 + 成交额达标**」的股票，
**每 5 个交易日评估一次建仓**、最多持 10 只、每只 10% 仓位，**持有满 30 个交易日**即卖出
（另有 5 条提前退出：质量恶化 / ST·跌停 / 过度兑现 / 止损（×p）/ 止盈（×p 或绝对 6%））。

**性质**：**中频 · 逆向 + 质量 + 低风险**（**不是**追涨）。

**性格**（必须清楚）：
- **持有期长、换手低** → 年化交易成本目标 **≤3%**（实测 **1.65%**），远低于 v1.6 的 7.8%
- **买的是"没人要的"**（反转 + 低波动 + 低换手）→ 收益来源与追涨策略完全相反
- **不做固定止盈、不设紧止损**（v1.5 已实测"止损越松越好"，紧止损会一起打掉赢家）
- **靠广度**：10 只分散，单票权重低 → 单票踩雷不致命

**为什么这么设计**（依据 `docs/回测与策略研究.md`）：
1. 根因：alpha 在**隔夜漏光**（买入强势股 → 次日平均低开 1.8%）→ **信号方向必须反着做**；
2. `ret_50` 分层单调性 **−1.00**（全组一致反向，形状最干净）；`volatility_20` −0.70、`turnover_20` −0.60；
3. `revenue_yoy` / `profit_yoy` 是全部因子里**唯二 IC 为正且单调 +1.00** 的 → 当**质量门**用（量级弱，不当收益引擎）；
4. 持有成本随频率急剧下降（10 日 4.9%/年 → 30 日约 1.9%）→ **频率本身就是 alpha 杠杆**。

### 2.2 开仓闸门（信号日 T 的截面，须全部通过）

> 可交易性过滤（非 ST/停牌/新股<90/一字板/非目标板块/60 日禁买）由**引擎股票池**负责，
> 策略侧**不重复实现**（见 `ctx.universe.symbols`）。

```
【门 1 · 大盘非急跌】
   上证指数 近 20 个交易日累计涨跌幅 > −10%
   → 否则本轮不建仓（已持仓不动）

【门 2 · 反转门（不追高）】
   rank_pct(ret_50) ≤ 0.50        —— 不买近 50 日最强的半数（截面百分位秩）
   AND max_ret_20 ≤ 0.15          —— 排除近 20 日内有涨停式脉冲的标的

【门 3 · 质量门（基本面成长）】
   profit_yoy > 0 AND revenue_yoy > 0
   —— 按**公告日 as-of 对齐**（NOTICE_DATE，防未来函数）
   —— 个股缺值 → 不通过（不猜）；因子整体不可用 → 该门降级并告警

【门 4 · 低风险门】
   volatility_20 ≤ 截面中位数
   AND turnover_20 ≤ 截面中位数

【门 0 · 流动性下限】
   amount_mean_20 ≥ 50,000,000 元   —— 近 20 日日均成交额
   —— 与 turnover_20 是**两个口径**：换手率按股本归一，成交额刻画"能承接多少钱"

【排序与执行】
   通过全部门的候选，按下面 5 个维度做**逐日截面百分位秩**后**等权平均**打分：
       · ret_50       方向 −1（越弱越好）
       · profit_yoy   方向 +1
       · revenue_yoy  方向 +1
       · volatility_20 方向 −1
       · turnover_20  方向 −1
   降序取前 N 只（N = max_positions − 当前持仓数），**空位才补，不强制换手**
   稳定排序 + 代码 tiebreaker（保证同一配置跑两次逐行一致）
   T+1 开盘买入，每只投入 10% × 当前总资产
```

**口径细节**：
- 百分位秩用 `pandas.Series.rank(pct=True)`（平均秩口径）；缺值（NaN）参与比较即为 False → **不通过**。
- **必须截面标准化再合成**：5 个维度量纲不同，直接相加等于让量纲大的独占权重。
- 打分维度至少要有 1 个可用，否则当日不建仓（不猜）。

### 2.3 退出规则（6 个条件，任一触发即卖出）

| # | 条件 | 判定口径 | 执行 |
|---|---|---|---|
| 1 | **到期换仓** | 持有满 `hold_days_max`（默认 30）个交易日（**含首尾**计数） | T 日尾盘收盘价卖出 |
| 2 | **质量恶化** | 当日已公告的最新一期 `profit_yoy < 0` **或** `revenue_yoy < 0` | T 日尾盘收盘价卖出 |
| 3 | **风险事件** | `isST = 1`，或收盘跌停 | ST → 收盘价卖出；**跌停 → 顺延 T+1 开盘**（红线：不按理想价撮合） |
| 4 | **过度兑现** | 近 20 个交易日累计涨跌幅 **≥ +30%** | T 日尾盘收盘价卖出 |
| 5 | **止损（v2.1）** | **毛收益率 ≤ −`stop_loss_p_mult` × p** | T 日尾盘收盘价卖出 |
| 6 | **止盈（v2.1）** | **毛收益率 ≥ `take_profit_p_mult` × p** **或** **≥ `take_profit_abs`** | T 日尾盘收盘价卖出 |

#### 条件 5/6 的精确定义与基准 `p`（v2.1 新增）⚠️

**阈值基准 `p` = 个股「近 5 日累计涨跌幅」的绝对值的 1/5**：

```python
r5 = ctx.market.cum_return(symbol, di, 5)     # close[di] / close[di-5] - 1（后复权，含首尾）
p  = abs(r5) / 5.0                            # 近 5 日【日均】涨跌幅的绝对值，小数
# p 是个股价、每只不同 → 阈值随个股近期波动自适应
gross = ctx.market.close_at(symbol, di) / pos.entry_price - 1.0     # 毛收益率

stop_loss   = stop_loss_p_mult  > 0 and p > 0 and gross <= -stop_loss_p_mult * p
take_profit = (take_profit_p_mult > 0 and p > 0 and gross >= take_profit_p_mult * p) \
              or (take_profit_abs > 0 and gross >= take_profit_abs)
```

- **不是振幅** —— 与 v1.4/v1.5 `momentum` 的「近 5 日平均振幅」是**不同口径**，别混用。
- **p 刻意取小**（日均口径，非 5 日累计）：一只近 5 日只动 2% 的票 → p ≈ **0.4%**，
  则 `1×p` 止损线仅 **−0.4%**，属**日内级**阈值。这是**有意选择**，网格里保留 **0 档（关闭）** 作对照。
- **0 = 关闭**：`mult <= 0` / `abs <= 0` 时该规则恒不触发（参数**默认全 0** → 行为与 v2.0/M1 基线一致）。
- `p` 不可用（`r5` 为 NaN 或 `p <= 0`）→ **不触发**（不误杀）。
- 全部**毛口径**（与条件 4 的 over_realized 一致）。
- 与其它条件**并存**：同一天多个条件成立时 reason 用 `|` 连接（如 `time_stop|stop_loss`）。

**多条件同时触发**：`reason` 用 `|` 记录全部（如 `time_stop|over_realized`）。

### 7.1 v2.0 建立（2026-10-06）

**三条读法**：

1. ✅ **首次跑出正的样本内年化**（+1.88%），且**笔均毛收益 +0.605%**（v1.2 是 **−1.45%**）

2. ✅ **成本按预期降下来了**：7.80% → **1.65%**（−4.7 倍）；最大回撤 −78.9% → **−28.2%**。
3. ⚠️ **但仍跑输基准 5.83pp**（= 仍无 alpha，只是缺口是历版最小）。
   ⚠️ **不是"降暴露"**：平均持仓 **8.26/10**、空仓天数仅 **0.4%**、平均现金 21.5%
   → 收益是真实暴露换来的，不是仓位缩小造成的假象。
   ⚠️ **超额缺口的部分原因是口径**：基准是**等权全市场**（含大量小盘股），
   而门 0（成交额 ≥5000 万）+ 门 4（低波动低换手）**系统性剔除了小盘股** ——
   策略吃不到基准里最大的一块 beta。

**出场结构（334 笔）**：

| 出场原因 | 笔数 | 平均净收益 | 平均持有 |
|---|---|---|---|
| `time_stop` | 281 | **−0.84%** | 30.0 |
| `over_realized` | 16 | **+33.41%** | 18.1 |
| `quality_broken` | 22 | −3.82% | 14.6 |
| `limit_down` | 12 | −11.99% | 16.8 |

→ **唯一盈利出口是"过度兑现"（16 笔，+33.4%），但只占 4.6%**；
主出口是"持满 30 天"（281 笔，−0.84%）—— **多数标的不涨就是这个策略的常态**，
收益靠少数吃到波段的标的撑起来。

**年度**：2020 +4.7% / 2021 +9.8% / **2022 −16.2%** / **2023 −3.8%** / 2024 +16.1%
→ 牛熊分化明显，**熊市年份仍亏**。

### 7.3 方法学警告（沿用）

1. **样本外已多轮使用**（v1.4 / v1.5 / v1.6 各一次）→ 只能当"方向一致性"参考，**不是干净 OOS**。
   M1 **未跑样本外**（留 M4，且只跑一次）。
2. **v2.0 与 v1.3/v1.4/v1.5 不可同口径对比**（规则、持仓周期、调仓节奏全变）。
   §7.2 的表只能当"版本沿革"读。
3. **本节只跑了 1 次基线，未做消融、未寻优** → 对"哪道门贡献了多少"**不给归因**。
   下一步（M3/M5）必须做逐门消融。

### 7.4 v2.1 变更：新增止损 / 止盈（2026-10-06）

| # | 问题 | **确认值** | 变更性质 |
|---|---|---|---|
| 11 | 是否加**止损** | **加**：`stop_loss_p_mult` × p，**默认 0 = 关闭** | ⚠️ 新增 |
| 12 | 是否加**止盈** | **加**：`take_profit_p_mult` × p **或** `take_profit_abs` 绝对档，**默认全 0 = 关闭** | ⚠️ 新增 |
| 13 | 阈值基准 `p` | **p = \|个股近 5 日累计涨跌幅\| ÷ 5**（近 5 日**日均**涨跌幅绝对值，**不是振幅**） | ⚠️ 新增（主人指定口径） |
| 14 | `over_realized`（ret_20 ≥ +30%）| **保留**，与新止损/止盈**并存**（任一触发即卖） | 无变更（保持与 M1 可比） |
| 15 | 参数默认值 | **全 0（关闭）** → 行为与 v2.0/M1 基线一致 | 变更边界 |
| 16 | 寻优网格 | 止损 5 × 止盈 6 × 持有期 5 × 持仓数 3 = **450 组** | ⚠️ 新增 |

**变更依据**：主人 2026-10-06 下达 ——
"止损：【0，p，1.5\*p，2\*p，3\*p】；止盈：【0，p，1.5\*p，2\*p，3\*p，6%】；
hold_days_max：【5，10，20，30，40】；max_positions：【2，5，10】；
**p 为近 5 日涨跌幅（不是振幅）**，6% 单独加是因为我比较感兴趣。"

**口径细节**：
- `p` 用**个股自身**的近 5 日累计涨跌幅 ÷ 5（`cum_return(symbol, di, 5)`，后复权、含首尾）。
- ⚠️ **p 刻意取小** → 阈值等价于**日内级**。例：近 5 日只动 2% 的票 → p ≈ 0.4%，
  `1×p` 止损线 −0.4%，几乎必被打掉。**这是有意选择**，网格里 0 档提供对照。
- **0 = 关闭**；`p` 不可用（NaN / ≤0）→ 不触发（不误杀）。
- 毛口径；与 `time_stop` / `quality_broken` / `st` / `limit_down` / `over_realized` 并存，reason 用 `|` 连接。
- 退出原因沿用既有枚举 `stop_loss` / `take_profit`（无需改契约、无需改前端）。

**⚠️ 与 v2.0 的对比纪律**：v2.1 新增了参数键 → `run_id` 哈希改变（预期）；
**默认全 0 时回测结果应与 v2.0 基线逐位一致**（已作为回归检查项）。

### 7.5 M3 逐门消融结果（2026-10-06）

**方法**：每次**只关一条规则**，其它全部保持默认，样本内跑一次（7 次）。
锚点 = 对齐口径 / 日再平衡基准年化 **+7.71%**。
**回归检查**：`v2.1-baseline` = **+1.88%**、334 笔、成本 1.65% —— 与 M1（v2.0）基线**逐项一致**
→ 证明"新参数默认 0 = 关闭"没有改变行为。✅

| 配置 | 年化 | 累计 | 最大回撤 | Sharpe | 笔数 | 年化成本 | 超额 | **Δ年化（vs 基线）** |
|---|---|---|---|---|---|---|---|---|
| **v2.1-baseline（全开）** | **+1.88%** | +8.94% | −28.23% | 0.19 | 334 | 1.65% | −5.83pp | — |
| 关 **反转门**（`reversal_pct=1.0`） | **−2.43%** | −10.74% | −39.36% | −0.05 | 334 | 1.66% | −10.14pp | **−4.31pp** |
| 关 **质量门** | +1.16% | +5.45% | −30.16% | 0.15 | 335 | 1.66% | −6.55pp | **−0.72pp** |
| 关 **低波动门** | +1.89% | +9.03% | −28.95% | 0.19 | 333 | 1.65% | −5.82pp | +0.01pp |
| 关 **低换手门** | +1.84% | +8.74% | −27.94% | 0.19 | 334 | 1.65% | −5.87pp | −0.04pp |
| 关 **流动性门** | **+3.18%** | +15.54% | −22.97% | 0.27 | 331 | 1.66% | −4.53pp | **+1.30pp** |
| 关 **过度兑现退出** | **+3.32%** | +16.24% | **−32.26%** | 0.27 | 329 | 1.63% | −4.39pp | **+1.44pp** |

**四条结论**：

1. ⭐ **反转门是策略的命根**：关掉它年化 **+1.88% → −2.43%**（−4.31pp），回撤恶化到 −39.36%。
   → 与预研一致（`ret_50` 分层单调性 −1.00 是全项目形状最干净的反向信号）。**这条不能动。**
2. ✅ **质量门有正贡献但量级小**（关掉 −0.72pp）→ 与基本面因子 IC 弱的实测一致：
   **它是个"锦上添花"的过滤器，不是收益引擎**。
3. ❌ **流动性门是负贡献**（关掉 **+1.30pp**，回撤从 −28.23% 改善到 −22.97%）。
   ⚠️ 但主人已明确"成交额下限 5000 万已足够、不再放宽" → **默认值保持不变**，
   本条只作为**证据记录**（它同时也解释了 M1 里那个"吃不到小盘 beta"的口径缺口）。
4. ❌ **过度兑现退出（ret_20 ≥ +30%）也是负贡献**（关掉 **+1.44pp**），
   代价是最大回撤从 −28.23% 恶化到 **−32.26%** → **是"收益换风险"的取舍**，不是纯粹变好。
   ⚠️ 它当初被设计成"唯一盈利出口"（M1 里 16 笔 +33.4%），但消融说明：**提前砍掉赢家不划算**。

**中性项**：低波动门（+0.01pp）与低换手门（−0.04pp）**在噪声范围内**，两条都可以说是白加。
→ 与它们的因子单调性（−0.70 / −0.60）不矛盾：单调性说的是**排序**，
而这里只用它们做了**中位数硬切**，切掉一半并没有换来更好的组合。

**⚠️ 纪律说明**：本节是**逐条消融**（一次只关一条），**不是**按出场原因分类统计；
结论给的是"关掉这条规则会怎样"，不是"亏损由这条规则造成"。
