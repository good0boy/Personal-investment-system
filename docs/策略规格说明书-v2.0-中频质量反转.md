## 1. 策略全貌

**一句话**：在上证指数近 20 个交易日未明显下跌时，买入沪深主板/创业板中
「**近期温和偏弱（反转）+ 基本面成长为正 + 低波动 + 低换手 + 成交额达标**」的股票，
**每 5 个交易日评估一次建仓**、最多持 10 只、每只 10% 仓位，**持有满 30 个交易日**即卖出
（另有 5 条提前退出：质量恶化 / ST·跌停 / 过度兑现 / 止损（×p）/ 止盈（×p 或绝对 6%））。

**性质**：**中频 · 逆向 + 质量 + 低风险**（**不是**追涨）。

**性格**（必须清楚）：
- **持有期长、换手低** → 年化交易成本目标 **≤3%**（实测 **1.65%**），远低于 v1.6 的 7.8%
- **买的是"没人要的"**（反转 + 低波动 + 低换手）→ 收益来源与追涨策略完全相反
- **不做固定止盈、不设紧止损**（v1.5 已实测"止损越松越好"，紧止损会一起打掉赢家）
- **靠广度**：10 只分散，单票权重低 → 单票踩雷不致命

**为什么这么设计**（依据 `docs/回测与策略研究.md`）：
1. 根因：alpha 在**隔夜漏光**（买入强势股 → 次日平均低开 1.8%）→ **信号方向必须反着做**；
2. `ret_50` 分层单调性 **−1.00**（全组一致反向，形状最干净）；`volatility_20` −0.70、`turnover_20` −0.60；
3. `revenue_yoy` / `profit_yoy` 是全部因子里**唯二 IC 为正且单调 +1.00** 的 → 当**质量门**用（量级弱，不当收益引擎）；
4. 持有成本随频率急剧下降（10 日 4.9%/年 → 30 日约 1.9%）→ **频率本身就是 alpha 杠杆**。

### 2.2 开仓闸门（信号日 T）

**三层结构**：① **大盘闸门**（市场级，每日判一次）→ ② **个股截面闸门**（逐只 AND 裁剪）→ ③ **打分排序取前 N**。

> 可交易性过滤（非 ST／停牌／新股 <90 交易日／一字板／非目标板块／60 日禁买）由**引擎股票池**负责，
> 策略侧**不重复实现**（见 `ctx.universe.symbols`）。

#### 2.2.1 闸门清单

| 编号 | 名称 | 层级 | 判定式（信号日 T 截面） | 参数键 | 默认 | 依赖因子 | 关闭方式 |
|---|---|---|---|---|---|---|---|
| **门1** | 大盘非急跌 | 市场级 | 上证近 20 交易日累计涨跌幅 **>** `index_ret20_min` | `index_ret20_min` | `-0.10` | 指数 `sh.000001` | `index_ret20_min: -1.0`（等效关闭） |
| **门2** ⭐ | 反转门（不追高） | 个股级 | `rank_pct(ret_50)` **≤** `reversal_pct` | `reversal_pct` | `0.50` | `ret_50` | `reversal_pct: 1.0`（等效关闭） |
| **门2b** | 排除脉冲股 | 个股级 | `max_ret_20` **≤** `max_ret_20_max` | `max_ret_20_max` | `0.15` | `max_ret_20` | ⚠️ **无独立开关**（只能把上限调大） |
| **门2c** ⚗️ | MA 上行确认（v2.3） | 个股级 | `MA_w(t)` **≥** `MA_w(t-1)`（后复权收盘价简单均线） | `ma_rise_confirm_window` | **0（关闭）** | 引擎行情矩阵（直算，非因子文件） | 设 **0**；w 可取 3 / 5 / 10 |
| **门3** | 质量门（成长为正） | 个股级 | `profit_yoy > 0` **且** `revenue_yoy > 0` | `use_quality_gate` | `true` | `profit_yoy` / `revenue_yoy` | `use_quality_gate: false` |
| **门4a** | 低波动 | 个股级 | `volatility_20` **≤** 截面中位数 | `use_lowvol_gate` | `true` | `volatility_20` | `use_lowvol_gate: false` |
| **门4b** | 低换手 | 个股级 | `turnover_20` **≤** 截面中位数 | `use_lowturn_gate` | `true` | `turnover_20` | `use_lowturn_gate: false` |
| **门0** | 流动性下限 | 个股级 | `amount_mean_20` **≥** `min_amount_mean_20`（元） | `use_liquidity_gate` / `min_amount_mean_20` | `true` / `50,000,000` | `amount_mean_20` | `use_liquidity_gate: false` |

> **编号 = 引入顺序，不是执行顺序**（门0 是后补的，编号给了 0）。实际执行顺序见 2.2.2。
>
> **门0 与门4b 是两个口径，别混**：`turnover_20` 按**股本**归一（换手率），
> `amount_mean_20` 刻画"**能承接多少钱**"（日均成交额，元）。

#### 2.2.2 执行顺序（与 `strategies/impl/quality_reversal.py::_apply_gates` 一一对应）

```
① 门1  市场级   上证近20日累计 > -0.10        ← 不通过则【当日不建仓】（已持仓照常按 §2.3 退出）
② 门2  反转     rank_pct(ret_50) ≤ 0.50
③ 门2b 脉冲     max_ret_20 ≤ 0.15
④ 门2c MA确认   MA_w(t) ≥ MA_w(t-1)          ← v2.3 新增，**默认关闭（w=0）**
⑤ 门3  质量     profit_yoy > 0 且 revenue_yoy > 0
⑥ 门4a 低波动   volatility_20 ≤ 截面中位
⑦ 门4b 低换手   turnover_20 ≤ 截面中位
⑧ 门0  流动性   amount_mean_20 ≥ 5,000 万元
→ 八个条件全部通过 = 候选
```

顺序**不影响结果**（AND 可交换），但决定**统计口径**：teardown 打印的是"该门**之后**剩余候选数"
（累计、单调不增），直接回答"每道门砍掉多少"。

#### 2.2.3 缺值 / 因子不可用（两条不同处理，别混）

| 情形 | 处理 |
|---|---|
| **个股缺值**（该股在该因子上是 NaN） | 该股**不通过**（`fillna(False)`）—— **不猜** |
| **因子整体不可用**（文件缺失，或该日不在截面） | 该门**降级不裁剪** + `logger.warning` 告警一次，并在 teardown 的"降级门"清单里列出 |

> 第二种是"**存在 ≠ 生效**"的防线：宁可放行并**显式告警**，也不能静默当成"这门过了"。

#### 2.2.4 打分排序与执行

通过全部门的候选，按 5 个维度做**逐日截面百分位秩**后**等权平均**打分：

| 维度 | 方向 | 含义 |
|---|---|---|
| `ret_50` | **−1** | 越弱越好（反转） |
| `profit_yoy` | **+1** | 成长越高越好 |
| `revenue_yoy` | **+1** | 成长越高越好 |
| `volatility_20` | **−1** | 波动越低越好 |
| `turnover_20` | **−1** | 换手越低越好 |

- 百分位秩用 `pandas.Series.rank(pct=True)`（**平均秩**口径，并列取平均名次）。
- **必须截面标准化再合成**：5 个维度量纲不同，直接相加 = 让量纲大的独占权重。
- 打分维度**至少 1 个可用**，否则当日不建仓（不猜）。
- 降序取前 `N = max_positions − 当前持仓数` 只 —— **空位才补，不强制换手**。
- 稳定排序 + 代码 tiebreaker → **同一配置跑两次逐行一致**。
- **每 `rebalance_every`（默认 5）个交易日才评估一次建仓**。
- **T+1 开盘买入**，每只投入 `max_weight_per_stock`（默认 10%）× 当前总资产。

### 2.3 退出规则（6 个条件，任一触发即卖出）

| # | 条件 | 判定口径 | 执行 |
|---|---|---|---|
| 1 | **到期换仓** | 持有满 `hold_days_max`（默认 30）个交易日（**含首尾**计数） | T 日尾盘收盘价卖出 |
| 2 | **质量恶化** | 当日已公告的最新一期 `profit_yoy < 0` **或** `revenue_yoy < 0` | T 日尾盘收盘价卖出 |
| 3 | **风险事件** | `isST = 1`，或收盘跌停 | ST → 收盘价卖出；**跌停 → 顺延 T+1 开盘**（红线：不按理想价撮合） |
| 4 | **过度兑现** | 近 20 个交易日累计涨跌幅 **≥ +30%** | T 日尾盘收盘价卖出 |
| 5 | **止损（v2.1）** | **毛收益率 ≤ −`stop_loss_p_mult` × p** | T 日尾盘收盘价卖出 |
| 6 | **止盈（v2.1）** | **毛收益率 ≥ `take_profit_p_mult` × p** **或** **≥ `take_profit_abs`** | T 日尾盘收盘价卖出 |

#### 条件 5/6 的精确定义与基准 `p`（v2.1 新增；**p 口径 v2.2 改版**）⚠️

**阈值基准 `p` = 最近 5 个交易日「每日涨跌幅绝对值」的均值**（小数）：

```python
lo   = di - 5 + 1
ts   = ctx.market.trade_status[lo:di+1, si]     # 1=可交易 / 0=停牌 / -1=无行
seg  = ctx.market.pct_chg[lo:di+1, si]          # ★ 单位是【百分数】（1.15 = +1.15%）
if not (窗口长度==5 and 全部 ts==1 and 全部 seg 有限):
    p = NaN                                     # → 本规则当日不触发（不误杀）
else:
    p = mean(abs(seg)) / 100.0                  # 近 5 日「日均绝对涨跌幅」，小数

gross = ctx.market.close_at(symbol, di) / pos.entry_price - 1.0     # 毛收益率

stop_loss   = stop_loss_p_mult  > 0 and p > 0 and gross <= -stop_loss_p_mult * p
take_profit = (take_profit_p_mult > 0 and p > 0 and gross >= take_profit_p_mult * p) \
              or (take_profit_abs > 0 and gross >= take_profit_abs)
```

- **不是振幅** —— 与 v1.4/v1.5 `momentum` 的「近 5 日平均振幅」是**不同口径**，别混用。
- ⚠️ **窗口内必须 5 天全部可交易**（`trade_status == 1`）且 `pct_chg` 有限，否则 `p` 不可用 → 不触发。
  为什么必须掩码：baostock 的**停牌日有行**（`has_data=True`），但 `trade_status=0` 且
  `pct_chg` 为 **0 或 NULL**（close 恒等于前收）—— 不掩码会把停牌日算进均值、**人为压低 p**。
- **`pct_chg` 是百分数** → 必须 ÷100（`engine.py` 里 `_mat("pct_chg")` 存的是 `1.15` 这种值）。
- **量级对照（实测 2024-11-15 全市场截面）**：

  | p 口径 | 中位 | 25% | 75% | 95% |
  |---|---|---|---|---|
  | v2.1 `\|近5日累计涨跌幅\|/5`（日间正负对消 → 偏小） | 0.93% | 0.52% | 1.52% | 2.83% |
  | **v2.2 `mean(\|日涨跌幅\|)`** | **2.25%** | 1.54% | 3.22% | 5.33% |

  → 新口径是旧口径的 **2.43 倍**：`1×p` 止损线由 −0.4%（"贴脸"）变成 **−2.25%（正常量级）**。
- **0 = 关闭**：`mult <= 0` / `abs <= 0` 时该规则恒不触发（参数**默认全 0** → 行为与 v2.0/M1 基线一致）。
- 全部**毛口径**（与条件 4 的 over_realized 一致）。
- 与其它条件**并存**：同一天多个条件成立时 reason 用 `|` 连接（如 `time_stop|stop_loss`）。

**多条件同时触发**：`reason` 用 `|` 记录全部（如 `time_stop|over_realized`）。

### 7.4 v2.1 变更：新增止损 / 止盈（2026-10-06）

| # | 问题 | **确认值** | 变更性质 |
|---|---|---|---|
| 11 | 是否加**止损** | **加**：`stop_loss_p_mult` × p，**默认 0 = 关闭** | ⚠️ 新增 |
| 12 | 是否加**止盈** | **加**：`take_profit_p_mult` × p **或** `take_profit_abs` 绝对档，**默认全 0 = 关闭** | ⚠️ 新增 |
| 13 | 阈值基准 `p` | **p = \|个股近 5 日累计涨跌幅\| ÷ 5**（近 5 日**日均**涨跌幅绝对值，**不是振幅**） | ⚠️ 新增（主人指定口径） |
| 14 | `over_realized`（ret_20 ≥ +30%）| **保留**，与新止损/止盈**并存**（任一触发即卖） | 无变更（保持与 M1 可比） |
| 15 | 参数默认值 | **全 0（关闭）** → 行为与 v2.0/M1 基线一致 | 变更边界 |
| 16 | 寻优网格 | 止损 5 × 止盈 6 × 持有期 5 × 持仓数 3 = **450 组** | ⚠️ 新增 |

**变更依据**：主人 2026-10-06 下达 ——
"止损：【0，p，1.5\*p，2\*p，3\*p】；止盈：【0，p，1.5\*p，2\*p，3\*p，6%】；
hold_days_max：【5，10，20，30，40】；max_positions：【2，5，10】；
**p 为近 5 日涨跌幅（不是振幅）**，6% 单独加是因为我比较感兴趣。"

**口径细节**：
- `p` 用**个股自身**的近 5 日累计涨跌幅 ÷ 5（`cum_return(symbol, di, 5)`，后复权、含首尾）。
- ⚠️ **p 刻意取小** → 阈值等价于**日内级**。例：近 5 日只动 2% 的票 → p ≈ 0.4%，
  `1×p` 止损线 −0.4%，几乎必被打掉。**这是有意选择**，网格里 0 档提供对照。
- **0 = 关闭**；`p` 不可用（NaN / ≤0）→ 不触发（不误杀）。
- 毛口径；与 `time_stop` / `quality_broken` / `st` / `limit_down` / `over_realized` 并存，reason 用 `|` 连接。
- 退出原因沿用既有枚举 `stop_loss` / `take_profit`（无需改契约、无需改前端）。

**⚠️ 与 v2.0 的对比纪律**：v2.1 新增了参数键 → `run_id` 哈希改变（预期）；
**默认全 0 时回测结果应与 v2.0 基线逐位一致**（已作为回归检查项）。

> ⚠️ **本节的口径细节（`p` 的定义）已被 §7.7 的 v2.2 取代** —— 下文保留原文以存档当时的决策。
> v2.1 的 `p = |近5日累计涨跌幅|/5` 已废弃，现为 `p = mean(|每日涨跌幅|)`。

- **6% 绝对档比任何 ×p 档都好**（在止损关闭行：−3.06% vs −2.90%~−4.48%），
  **但仍远差于"不加止盈"（+0.10%）** → **主人点名想看的 6% 档，结论是"比 ×p 好，但依然不该加"。**
- 38 个正收益组里 **33 组是"关止盈"**（4 组 p×档、1 组 6% 绝对）。

#### ⭐ 核心结论 2：止损呈 **U 形** —— 极紧有害、极松略优，"贴脸止损"实锤

| 止损档 | 年化均值 | 笔数均值 | 年化成本均值 | 回撤均值 |
|---|---|---|---|---|
| **0.0（关闭）** | −2.93% | 531 | 2.63% | −21.51% |
| **1.0（最紧）** | **−7.26%** | **1023** | **5.09%** | **−32.49%** |
| 1.5 | −6.74% | 1011 | 5.02% | −32.19% |

- **1×p 止损让成交笔数从 531 → 1023（翻倍）、年化成本 2.63% → 5.09%、回撤恶化 11pp** ——
  这就是 `p` 取**日均口径**（典型 ≈0.4%）导致"**贴脸止损**"的**实锤**。
- **止损越松，笔数/成本/回撤都回落**（3.0 档回到 957 笔 / 4.73% / −26.91%）。
- 在**关闭止盈**的条件下：止损 1.0 −2.18% / 1.5 −1.61% / 2.0 −0.64% / **0.0 +0.10% / 3.0 +0.85%**
  → **U 形：两端最好，中间最差**；3.0 略优于关闭，但差异很小（+0.75pp），在噪声范围内。

**与 v1.4 §3.9 的结论完全同构**：这一维是**波动率的缩放**，不是 alpha。

**疑点 B · 收益结构是"彩票型"，且换手/成本翻倍**

| 配置 | 入场票成交额分位中位 | 胜率 | 年化成本 | 平均持有 |
|---|---|---|---|---|
| 基线 | 60.7% | 43.7% | 1.65% | 27.9 日 |
| 合并档 | 37.3% | 46.1% | 1.65% | 28.0 日 |
| **合并 + sl1.25×p** | **33.5%** | **20.6%** | **3.94%** | **10.3 日（中位 4 日）** |

- **77.8% 的交易是止损出场**（628 笔，合计毛亏 **−191.8 万**），**全部收益来自 19.1% 的 `time_stop` 赢家**（154 笔，**+281.5 万**）。
  → 这里的止损不是"保护"，而是**"不涨就换"的换手加速器**。
- 换手翻 **2.4 倍**（334 → 807 笔），成本 1.65% → **3.94%** → **对成本/滑点假设变得高度敏感**。
- 关掉流动性门后入场票成交额分位 60.7% → 33.5% → **策略吃到了更多小盘暴露**；基准本身是等权全市场（含小盘），
  但这条意味着 **收益里有一部分是小盘 beta 而非 alpha**。

#### 7.10.4 一句话总结（v2.2 · M3c）

> **✅ 全项目第一次出现正超额**（合并 + sl1.25×p → +13.05%、超额 **+5.34pp**、Sharpe 0.79）；

> 止损符号跨域翻转、胜率仅 20.6%、77.8% 交易靠止损出场、成本翻 2.4 倍

### 7.13 M6 风格 / 暴露归因：策略赚的是 beta，不是 alpha（2026-10-07）

**动机**：§7.12.5 只是**方向性判断**（"涨市跑输 / 跌市抗跌 = 低 beta"），没有量化。
本节用新工具 **`tools/style_attribution.py`** 把策略收益对一组风格因子做 OLS，回答三个问题：
持仓暴露在哪些风格上？α 是否显著？风格 β 解释了多少波动？

**方法**（口径复用 `factors.analyze`，与因子分析同源；详见工具 docstring）：

- 风格因子为**日频 long-short**：截面分位 q=30% 分组、**次日等权**收益，long 侧一律取策略偏好的那一端。
- 回归：`r_strategy = α + β₁·MKT + β₂·SMB + β₃·VOL + β₄·TURN + β₅·MOM + β₆·GROW`（日频，含常数项）。
- `MKT` = 池内等权次日收益（对齐口径）；`SMB` 小−大市值；`VOL` 低−高波动；`TURN` 低−高换手；
  `MOM` 低−高动量（`ret_50`）；`GROW` 高−低成长（`profit_yoy`+`revenue_yoy` 平均秩）。
- 复现：`python -m tools.style_attribution --tag <回测tag>`

#### 7.13.1 回归结果（三个窗口）

| 窗口 | 天数 | **α 年化** | **t(α)** | MKT | SMB | VOL | TURN | MOM | GROW | **R²** |
|---|---|---|---|---|---|---|---|---|---|---|
| 样本内 2020-06~2024-12 | 1114 | **−8.59%** | **−1.74** | 0.739*** | −0.343*** | +0.185*** | +0.284*** | +0.274*** | +0.110** | **0.674** |
| 牛市OOS 2025-01~2026-09 | 414 | −3.25% | −0.44 | 0.853*** | −0.444*** | +0.221** | +0.415*** | +0.204*** | +0.031 | **0.696** |
| 非牛市 2025-12~2026-09 | 195 | +19.99% | +1.44 | 0.782*** | −0.684*** | +0.577*** | +0.036 | +0.218*** | −0.272* | **0.590** |

（*** |t|≥2.58 ／ ** |t|≥1.96 ／ * |t|≥1.65）

**读数 ①：α 在三个窗口全部不显著**（t = −1.74 / −0.44 / +1.44，**全部 |t| < 1.96**），
而且**符号翻转**（样本内与牛市为负、非牛市为正）。
→ **没有任何"选股 alpha"的证据；点估计在样本内是 −8.6%/年。**

**读数 ②：风格 β 高度稳定、且几乎全部显著**：

- **MKT 0.74~0.85（全 ***）** → 市场暴露约 0.8（与"83% 仓位"自洽）
- **SMB −0.34 ~ −0.68（全 ***）** → **系统性偏向大市值**（远离小盘）
- **MOM +0.20~+0.27（全 ***）** → 稳定的"近期弱势/反转"暴露
- VOL +0.19~+0.58、TURN +0.04~+0.42 → 低波动、低换手暴露（方向稳定、量级有波动）
- GROW −0.27~+0.11 → ⚠️ **唯一不稳定的维度**（尽管持仓成长分位高达 92~94%，β 却有时为负）

**读数 ③：R² = 0.59 ~ 0.70** → 策略日收益波动的**六到七成由风格解释**。

#### 7.13.2 持仓暴露（市值加权平均截面分位；全池中位 = 50%）

| 风格 | 样本内 | 牛市OOS | 非牛市 | 读法 |
|---|---|---|---|---|
| SMB 小市值 | 62.9% | 51.7% | 52.8% | 略偏**大**市值 |
| VOL 低波动 | **25.3%** | **21.4%** | **22.7%** | 显著**低**波动 |
| TURN 低换手 | **17.8%** | **16.1%** | **18.0%** | 显著**低**换手 |
| MOM 低动量 | **25.6%** | **25.2%** | **28.7%** | 显著**近期弱势**（反转） |
| GROW 高成长 | **91.5%** | **92.9%** | **93.8%** | 显著**高**成长 |

**跨窗口极稳** —— 这五个分位在三个窗口里几乎不动（波动 ≤ 3pp）。

#### 7.13.3 结论：这个策略到底是什么

> **`quality_reversal` 的本质 = 一个「低波动 + 低换手 + 近期弱势(反转) + 高成长 + 略偏大市值、市场暴露 ≈0.8」的风格组合。**
>
> - 它的 **日收益 60~70% 由这些风格解释**（R² 0.59~0.70）；
> - **残差 α 在三个窗口里全不显著**（t 全部 < 1.96），点估计在样本内为 **−8.6%/年**；
> - 这**直接解释了 §7.11/§7.12 的"涨市跑输、跌市抗跌"** —— 就是 β≈0.8 + 低波动的机械结果；
> - 也解释了**为什么调参/加规则总是符号翻转**（§7.9~§7.12）：那些改动**不改变风格暴露本身**，
>   只是在残差（≈30% 的波动）里加噪声。
>
> **→ 结论与 §7.11/§7.12 一致，但这次是量化证据：策略赚的是 beta（风格暴露）的钱，不是 alpha 的钱。**

**⚠️ 方法学限制**：风格因子由本地因子库构造，q=30% 分组、次日等权，**未做风格间的正交化**
（例如低波动与低换手本身正相关：两者都指向"冷门股"），所以各 β 之间不是完全独立归因；
但 α 不显著这一结论对正交化方式不敏感（R² 已解释七成，残差本就很小）。

#### 7.14.4 附带实验：持仓集中度敏感性（主人指定，2026-10-09）

固定 `oosma10-base` 全部参数（MA10 门、基线域），区间牛市OOS（基准 +15.64%），两组设计：

**(b) 主实验 · 等暴露**：总仓始终 ~80%（受候选数与整手取整限制，三档一致），

|---|---|---|---|---|---|---|---|---|---|

**回答主人的问题「集中持仓是否震荡剧烈」：是，且单调、清晰。**

1. **波动随集中度单调放大**：日收益 std 1.07% → 1.30% → 1.68%（年化 16.7% → 20.3% → 26.2%）；
   单日 \|涨跌\|>2% 的天数 25 → 50 → 67（2.7 倍）；最大回撤 −12.65% → −19.89%（深 7pp）。

   **高集中 = 高弹性 + 高震荡，2026 震荡市里集中持仓波动放大 ~60% 而收益反而垫底**。
3. **分散（10 只）的路径最平滑**：年度间收益差最小（+52.9% / +9.6%），Sharpe 最高（1.93）。
4. ⚠️ 样本警示：2 只组合全程仅 27 笔，收益排名由 2025 单年驱动，运气成分极大；
   且整组建立在 §7.14.2 已判定的单窗口离群配置上 → **绝对数字不可采信，
   可迁移的只有「集中度 ↔ 波动」的单调关系（这是分散化的数学，不是 alpha）**。
