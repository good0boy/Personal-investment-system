## 0. 结论先行（TL;DR）

**继续在现役动量模板上拧参数/闸门/止损，已经确定拿不到 alpha（四条路 600+ 组寻优全部为负）。
要么换信号方向，要么换持仓周期 —— 本方案两样都换。**

一句话：**放弃"日频追强势股"，改为「每 5 个交易日调仓、持有 20~40 个交易日」的中频「温和弱势 + 基本面成长 + 低波动」选股。**

三条支撑（全部来自本项目实测，不是外来经验）：

1. 🔴 **现役策略的病根在"买入侧"**：alpha 在**隔夜跳空**就漏光（入场 −1.82%/−1.70%，76% 低开）。
   这是"买当日/近期最强势股"必然付出的成本 —— 只要**还是买强势股**，怎么改出场都没用（v1.6 已验证：改出场 = 二阶影响）。
   ⇒ **必须把信号买在反转的正确一侧**：不追强，改买"温和弱势"。
2. ⭐ **反转信号真实存在且"形状干净"**：`ret_50` 分层单调性 **−1.00**（全组一致反向，不是只有极端组崩坏）；
   `volatility_20` −0.70 / `turnover_20` −0.60（低波动、低换手更好）；
   而**唯二 IC 为正且单调 +1.00 的因子是 `revenue_yoy` / `profit_yoy`**（基本面成长）。
   把这几条正交维度**低频**组合，是现成的、有证据的方向。
3. ⭐ **换手成本随频率**急剧**放大**：持有 5 日 ≈ **9.8%/年**、10 日 4.9%、20 日 **2.4%**、40 日 **1.2%**（规格书第 3 章）。
   日频合成的成本是 **30%/年**（把 +23.7% 毛收益吃成 −6.3%）——**同一个合成信号，放到 20~40 日频率成本可降到 1/10**。
   ⇒ **频率本身就是最大的 alpha 杠杆。**

> **落点：把换仓频率放在 20~40 交易日这一档。**
> 不建议 1~10 日（成本 5~44%/年，且正是隔夜反转最伤人的档位），也不建议纯季度（反馈太慢、无法证伪）。

## 1. 为什么要重构（诊断回顾）

### 1.1 现役（v1.2→v1.6）走过的四条路，全部失败

| 路 | 做了什么 | 结果 |
|---|---|---|
| ① 调参 | v1.4 的 72 组网格（止盈×持有期×仓位×持仓数） | **0/72 为正**，最好 −4.74%；"最优"= **降暴露**（仓位/持仓越小越"好"） |
| ② 剔极端组 | v1.3 剔除 `momentum_20` 最高 20%（G5） | 样本内 −49.5% → −3.9%（**止损式修复**），但**仍跑输基准 11.6pp**，不是造 alpha |
| ③ 加闸门/收紧止损 | v1.5：新增"近期无涨停"门 + 止损 1.2× | **192 组 0 为正**；两条新规则被**自己的内置消融**否掉（门开着更差、止损越松越好） |
| ④ 换成交时点 | v1.6：清仓改 T 日尾盘收盘价（336 组寻优） | |Δ| 全 ≤4pp、**结构指标纹丝不动** → 出场时点是**二阶变量** |

**四条路的共同点，也是它们必然失败的原因**：①~④ **全都是"买强势股 + 短持有"这一个模板的局部改动**，
始终没有动过 **信号方向** 与 **持仓周期** 这两个真正决定赔率的变量。

### 1.2 根因（一句话）

> **买"当日涨 1~5%、前期涨超 5%"的强势股 → 这些股次日平均低开 1.8%（A 股短期反转）→ 亏损在成交那一刻就已注定，之后任何出场规则只是把它"确认"了。**

证据链（§1 边际分解 + §3 因子 IC + §3.11 口径对照，三条独立路径互证）：
- 逐笔分解：隔夜跳空 **−1.822%/−1.701%**，持有段 −1.45%/−0.03%（≈0）→ **亏在入场**。
- 截面秩相关：15 个日度因子 **IC 全为负**，`momentum_20` t 值 −8.98。
- 受控对照（v1.6）：只改卖出时点，结构指标不变 → 反向印证问题在**买入侧**。

## 2. 证据盘点：哪些信号值得用

> 只列**本项目实测过**的。来源：`docs/回测与策略研究.md` §3.1 / §3.4 / §3.5 / §3.7。

| 因子/维度 | IC | 分层单调性 | 年化换手成本 | 读法 |
|---|---|---|---|---|
| `ret_50` 近50日收益 | −0.0374 | **−1.00** | 6.9% | **形状最干净的反转信号**（全组一致）→ 反向用（买低分位） |
| `volatility_20` 波动率 | −0.0496 | −0.70 | 3.9% | 低波动更好，单调性尚可 |
| `turnover_20` 换手率 | −0.0413 | −0.60 | 1.4% | 低换手更好，成本极低 |
| `max_ret_20` 最大单日涨幅 | −0.0498 | −0.70 | 3.7% | 排除"脉冲股"（与 G5 崩坏同源） |
| `momentum_20` 动量 | −0.0378 | −0.10 | 10.2% | ⚠️ **形状是"G5 单独崩坏"不是平滑反转** → 只能"剔除"，不能"取负" |
| `revenue_yoy` 营收同比 | **+0.0015** | **+1.00** | **0.5%** | ✅ 唯二正 IC 且单调；但量级弱 → **当质量过滤，不当主信号** |
| `profit_yoy` 归母净利同比 | **+0.0035** | **+1.00** | **0.6%** | 同上（ICIR 0.046，t≈1.8，**统计不显著**） |
| （对照）`combo_eq3` 日频三簇合成 | −0.0547 | −0.10 | **30.0%** | 信号更稳（\|ICIR\| 0.386）但**成本吃光** → 日频不可交易 |

**三条判读（决定设计）**：

1. **价格侧的主信号是"反转 + 低波动/低换手"，不是动量。** 选它们因为**形状**（单调性 −0.6~−1.0），
   而非只看首尾差 —— 符合 §4 纪律 4。
2. **`momentum_20` 只能"剔除极端"不能"取负"**（G1~G4 齐平 +18%~+23%、只有 G5 −8.9%，取负会把 G1~G4 也做反）。
   故 v2.0 不直接用它，改用 `ret_50`（全组一致）与 `max_ret_20`（排除脉冲）。
3. **基本面当"质量门"，不当收益引擎**：IC 量级接近噪声，但它的**成本优势（0.2~0.6%/年）是真实且大**的，
   恰好适合"低频过滤 + 中长期持有"的用法。

## 3. 策略 v2.0 设计

### 3.1 定位与性格

| 项 | 值 |
|---|---|
| 一句话 | 在上证指数未处于急跌段时，买入沪深主板/创业板中「**近期温和偏弱（反转）+ 基本面成长为正 + 低波动低换手**」的股票，每 5 个交易日评估调仓，**持有 20~40 个交易日**，最多 8~10 只、每只约 10~12% 仓位 |
| 性质 | **中频 · 逆向 + 质量 + 低风险**（不是追涨） |
| 赌什么 | ①中期（50 日尺度）反转持续存在且形状干净；②基本面成长股有溢价；③低波动/低换手在 A 股中长期有效；④**低频 = 低成本**，让毛收益不被交易成本吃掉 |
| 不赌什么 | ❌ 短期动量延续（已反复证否）❌ 择时抓拐点 ❌ 单票爆发 |

### 3.2 回测设置

| 项 | 值 | 说明 |
|---|---|---|
| 区间 | 样本内 **2020-06-01 ~ 2024-12-31**；样本外 **2025-01-01 ~ 2026-09-16** | 与现役同，便于对照 |
| 股票池 | 沪深主板 + 创业板全市场（含退市股） | 同现役 |
| **额外池限制** | **须有基本面数据**（`profit_yoy`/`revenue_yoy` 非空） | 缺则不入池，防"没有质量信息的标的"混入 |
| **调仓节奏** | **每 5 个交易日** 生成一次信号（可参数化 `rebalance_every`） | 不是每日选股 |
| **目标持有期** | **20 / 30 / 40 交易日**（`hold_days_max`） | 核心变量，进网格 |
| 持仓数 | **8 / 10 只**（`n_positions`） | 比现役更分散 |
| 单票仓位 | **10% / 12.5%**（按当前总资产） | 8×12.5%=100% |
| 未用满仓位 | 留现金 | 同现役 |
| 成交（买入） | T 日信号 → **T+1 开盘价** | 沿用数据红线 |
| 成交（卖出） | T 日信号 → **T 日尾盘按收盘价**（跌停/停牌顺延 T+1 开盘） | 沿用 v1.6 引擎口径 |
| 禁买窗口 | 卖出后 **60 交易日** | 沿用 |
| 新股门槛 | 上市满 **90 交易日** | 沿用 |
| 成本 | 走 `cost_model.py`（佣金/印花税分段/过户/滑点 5bp/整手） | 唯一实现，不得硬编码 |
| 初始资金 | 1,000,000 元 | |

> 📌 **为什么是"每 5 日评估、持有 20~40 日"**：让**同一批持仓的生命周期跨越多个评估日**，
> 避免"每日全量换仓"（那是 30%/年成本的来源）。实际换手应落在 **每 4~8 周完整换一轮**的量级，
> 目标年化成本 **≤3%**（对照现役 v1.6 的 7.8%）。

### 3.3 开仓闸门（信号日 T 的截面，全部须通过）

> 可交易性（非 ST/停牌/新股<90/一字板/非目标板块/60 日禁买）由**引擎股票池**负责，策略不重复实现。

```
【门 0 · 流动性下限】
   近 20 日日均成交额 ≥ 5000 万元
   —— 排除流动性陷阱（中频持有要能进能出）
   ⚠️ 需成交额数据（见 §6 工程改动）

【门 1 · 大盘非急跌】（沿用现役闸门 1 的精神，可放宽）
   上证指数近 20 个交易日累计涨跌幅 > −10%
   —— 不抓拐点，只回避系统性急跌段（比现役"逐日 > −1%"宽松，
      因为中频策略不需要择时到日）

【门 2 · 反转门（不追高）】
   ret_50 ≤ 截面 50 分位          （不买近 50 日最强的半数）
   AND max_ret_20 ≤ 某阈值（如 0.15）  （排除 20 日内有涨停式脉冲的标的）

【门 3 · 质量门（基本面成长）】
   profit_yoy > 0 AND revenue_yoy > 0
   —— 用**绝对值正号**（不是分位），避免极值；也可退化为"≥ 截面 40 分位"
   ⚠️ 缺值 → 不通过（不猜）

【门 4 · 风险门（低波动 + 低换手）】
   volatility_20 ≤ 截面中位数
   AND turnover_20 ≤ 截面中位数

【排序与执行】
   通过全部门的候选，按「反转 + 质量 + 低波动 + 低换手」的多因子截面秩等权合成打分，降序取前 N
   （N = n_positions − 当前持仓数，仅补空缺；不强制换掉已有持仓，除非触发退出条件）
   T+1 开盘买入，每只投入 10%~12.5% × 当前总资产
```

**排序键的定义（关键，别写错）**：
每一维先做**逐日截面百分位秩（0~1）**，再按方向加权（越高越好 = 1−秩 或 秩 取正）等权平均。
- 反转维：`ret_50` 用 **(1 − 秩)**（越弱越好）；
- 质量维：`profit_yoy`、`revenue_yoy` 用 **秩**（越强越好）；
- 低波动/低换手：`volatility_20`、`turnover_20` 用 **(1 − 秩)**。
> ⚠️ **必须截面标准化再合成**（量纲不同，直接相加 = 让量纲大的独占权重）—— 这是 §3.5 合成时的既定做法。

### 3.4 退出规则（4 条，任一触发即卖）

| # | 条件 | 判定口径 | 执行 |
|---|---|---|---|
| 1 | **到期换仓** | 持有满 `hold_days_max`（20/30/40）个交易日 | T 日尾盘收盘价卖出 |
| 2 | **质量恶化** | 新公告后 `profit_yoy < 0` **或** `revenue_yoy < 0` | T 日尾盘收盘价卖出 |
| 3 | **风险事件** | `isST = 1` 或 跌停 | ST→收盘价卖出；跌停→顺延 T+1 开盘（红线） |
| 4 | **过度兑现** | `ret_20 ≥ +30%`（反转已兑现甚至过热） | T 日尾盘收盘价卖出 |

> ⚠️ **刻意不设"日内级紧止损"**：v1.5 已实测**止损越松越好**（2.0× −15.4% vs 1.2× −18.9%），
> 紧止损会同时打掉赢家（持有期 7.3→5.7 天、成本升到 7.8%）。中频策略更不该用贴近日常振幅的止损线。
> 若要做风控，只用**宽松的**账户级回撤控制（见 §5 风险）。

## 4. 与现役 v1.6 的本质差别（一张表看清"到底改了什么"）

| 维度 | 现役 v1.6 | **新 v2.0** | 为什么这么改 |
|---|---|---|---|
| **信号方向** | 买**最强**（动量/涨幅/振幅排序） | 买**温和弱势**（反转）+ 质量 | 根因：买强势股隔夜 −1.8%，方向错了 |
| **持有期** | ≤10 日（实际 5~7） | **20~40 日** | 稀释入场日 ±1.8% 跳空；成本 4.9%→2.4%/1.2% |
| **信号频率** | 每日选股 | **每 5 日评估** | 换手来源从"日内噪声"变"季度财务+中期价格" |
| 持仓数 | 5 | **8~10** | 逆向选股靠广度，降低单票踩雷 |
| 个股止损 | 1.2×均振幅（紧） | **不设/极松** | v1.5 实测"越松越好" |
| 止盈 | 6% 固定 | **不做固定止盈**（用"过度兑现"退出） | 中频收益不该被 6% 截断 |
| 大盘择时 | 近 3 日逐日 > −1%（日频） | 近 20 日 > −10%（粗） | 中频不需要日频择时 |
| 加仓逻辑 | 每日补满空槽 | **仅补空缺**，不强制换手 | 控换手 |
| 成本（目标） | 7.8%/年 | **≤3%/年** | 频率红利 |

## 5. 风险与失效模式（诚实清单）

| # | 风险 | 应对 |
|---|---|---|
| 1 | **长仓做多反转 = 抄底 → 可能接到价值陷阱/退市股** | 质量门（成长为正）+ ST/停牌过滤 + 8~10 只分散 + 纳入退市股诚实计价 |
| 2 | **基本面因子 IC 统计不显著**（t≈0.7~1.8） | 只当**过滤门**、不当收益引擎；`profit_yoy` 极值先缩尾 |
| 3 | **基准（等权全市场）本身是小盘 beta（+7.71%/+15.64%），很难跑赢** | 目标先设"**跑平/小幅超额 + 更低回撤 + 更低成本**"，不预设高 alpha；超额不达标就诚实记录 |
| 4 | **行业集中**：低波动/反转可能整行业扎堆 | Phase 2 做**行业中性化**（需 baostock 行业分类，见 §6）；先看基线是否已集中 |
| 5 | **反转收益可能仍集中在少数交易日** | **必须看分层形状**（§4 纪律 4），不能只看首尾差 |
| 6 | **换手成本预估可能偏乐观** | 实测日均换手/年化成本，直接与 combo 的 30%、现役的 7.8% 对照 |
| 7 | **样本外已被看过多次（v1.4/v1.5/v1.6 各跑过）** | 只能当"方向一致性"参考，**不是干净 OOS**（沿用 v1.6 的方法学警告） |
| 8 | **调仓成本**：8~10 只 × 每 5 日 | 实测；必要时把 `rebalance_every` 调到 10 |

**明确的"不做"**（沿用已有证据）：
- ❌ 不给现役动量模板继续调参/加闸门（四条路已穷尽）。
- ❌ 不把动量信号"取负"（G1~G4 会一起做反）。
- ❌ 不做日频合成（成本 30%/年）。
- ❌ 不为了"跑出正数"而改引擎。

## 7. 验证计划（按本项目分析纪律执行）

1. **先算基准**（对齐口径 / 日再平衡）：样本内 **+7.71%**、样本外 **+15.64%**。**没有基准不下结论。**
2. **基线回测**（样本内，1 次）→ 看：是否为正、是否跑赢基准、年化成本、日均换手、最大回撤。
3. 🔬 **消融（强制）**：逐条关掉 质量门 / 低波动门 / 流动性门 / 反转门，**单独重跑**，
   回答"哪条真的贡献"—— **不许用"按出场原因分类统计"代替消融**。
4. 💰 **成本核算**：年化换手、年化成本、日均换手 —— 与 combo（30%）、现役 v1.6（7.8%）对照。
5. 📊 **形状检查**：合成打分/各单因子的**分层回测图**，确认不是"仅极端组崩坏"。
6. 🧾 **归因**：拆**已实现 / 未实现**、按出场原因、按板块。
7. **样本外**：规则冻结后**只跑 1 次**；并⚠️标注"非干净 OOS"。
8. **网格寻优**：样本内，含各门 `off` 档；用**高原（邻域均值）**不用单点最优。

**判据（什么算"值得继续"）**：
- ✅ 基线**为正** 且 **超额 ≥ 0**（跑平或跑赢对齐基准），且 **年化成本 ≤ 3%** → 进入寻优。
- ⚪ 基线为正但超额为负 → 检查是否只是"降暴露"（若是，同 v1.4/v1.5 结论：无 alpha）。
- ❌ 基线为负 → 归因到具体门（消融），**不继续调参**。
